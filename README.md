# Heavy Suppliers Warehouse Analysis

## Project Overview

This project focuses on analyzing Heavy Suppliers Warehouse datasets to understand
business operations, customers, products, inventory, invoices, payments, and other
business processes.

## Objectives

- Understand the structure of the available datasets
- Perform data profiling and quality analysis
- Identify primary and foreign keys
- Understand relationships between tables
- Identify missing values and data inconsistencies
- Define relevant business KPIs
- Perform data analysis
- Develop dashboards and insights
