# Week 5 — Inventory Analysis and Stock Health

## Overview
Week 5 focuses on inventory analysis, stock health validation, inventory movement, ABC classification, and inventory turnover. The deliverables include analysis files, validation outputs, sprint documentation, and a Power BI dashboard.

## Key Findings
- The detailed inventory analysis covers **180 product–branch combinations** across 30 products and 6 branches.
- No duplicate product–branch pairs were identified.
- All 180 combinations were flagged because current stock exceeds the recorded maximum stock. These flags require validation of units, quantities, and maximum-stock definitions before being interpreted as confirmed overstock.
- Fourteen combinations show a mismatch between current stock and the latest available running balance.
- The ABC classification contains 23 Class A, 5 Class B, and 2 Class C products. The classification thresholds and calculation logic should be verified before operational use.
- The provisional inventory valuation is ₹281,292,677,410. It should not be treated as confirmed until the quantities, units, unit costs, and valuation assumptions have been validated.
- Inventory turnover figures are provisional analytical proxies, not confirmed annual turnover KPIs.
- The latest movement date in the available data is 28 January 2025. This does not establish whether inventory activity continued after that date.
