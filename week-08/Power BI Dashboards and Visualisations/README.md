# Power BI Dashboards and Visualisations

This folder contains the Power BI dashboard resources and visual outputs developed for the Week 08 Customer Analytics and Segmentation analysis.

## Files Included

- Power BI dashboard screenshots
- Customer Purchase Behaviour and RFM Analysis visualisations
- Customer Value, Retention and Churn Analysis visualisations
- Power BI report file (.pbix), if available
- Other supporting dashboard images and exports

## Dashboard Overview

The dashboards present key insights into customer purchasing patterns, RFM segmentation, customer value, repeat purchases, retention, and potential churn indicators.

They provide a visual representation of the analysis findings and help communicate important customer trends.
