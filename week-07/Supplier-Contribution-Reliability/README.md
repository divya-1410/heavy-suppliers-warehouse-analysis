# Supplier Contribution and Reliability

## Overview

This analysis evaluates supplier procurement contribution, purchase value, order volume, and delivery reliability using the integrated purchase order dataset.

## Analysis Areas

- Supplier-wise procurement spend and purchase value.
- Supplier contribution and order volume comparison.
- On-time, late, and early delivery performance.
- Supplier delivery reliability using unique received purchase orders.
- Delivery delay analysis where receipt-date information is available.
- Comparison of supplier performance using available procurement metrics.

## Supporting Files

- `Week_07_Final_Supplier_Analytics.xlsx` – Supplier analysis workbook.
- `WEEK 07 POWER BI.pbix` – Interactive Power BI dashboard.
- Dashboard visualisations – Graphical representation of procurement and delivery performance.

## Objective

To understand supplier contribution and reliability, compare procurement performance, and establish validated supplier performance measures for the Week 7 supplier and procurement analytics analysis.
